## Preview locally
Open `index.html` in a browser. For a more reliable local preview, use Visual Studio Code with the Live Server extension.

## Publish free with GitHub Pages
1. Sign in at https://github.com/
2. Create a new **public** repository named `megha-portfolio` (or another name you prefer).
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder if using it. Keep the files in the repository root, not nested inside another folder.
4. Open the repository's **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then Save.
7. Wait for the deployment to complete. Your site URL will look like `https://YOUR-USERNAME.github.io/megha-portfolio/`.
8. Open the URL in a private/incognito browser window to confirm it is public.
